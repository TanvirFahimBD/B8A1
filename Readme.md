# B8A1 - Assignment: Problem Solving with Typescript & OOP

## Assignment Overview

This assignment focuses on understanding and practicing fundamental Typescript concepts, including function, union type, tuples, generics, interfaces, OOP, access modifiers, and anynchronous programming. 

The solutions are implemented in TS, and the theoretical concepts are explained throught two separate blog posts with practical examples.

## Assignment Solutions

The `solutions.ts` file contains practical implementations of the following concepts:

- Functions with default parameters
- Union types and type narrowing
- Tuple destucturing
- Generic functions and array operations
- Interfaces and filtering data
- Generic constraints with `keyof`
- Classes, inheritance, and access modifiers
- Asynchronous programming with promieses

## Blog posts

The following blog posts explain two important TS concepts with practical code examples: 

1. **[Understanding Access Modifiers in TypeScript OOP](./access-modifiers-in-ts.md)**

    Explains `public`, `private`, `protected`, and `readonly` access modifiers and how they work in TS classses.

2. **[Combining Union (|) and Intersection (&) Types in TS](./union-intersection-in-ts.md)**

    Explains the differences between Union and Intersection types and demonstrates how to combine them in practical applications.
